# Textures

Vide en phase 0 : uniquement des materiaux de couleur unie (contrainte 4).

A partir de la **phase 1**, si tu veux habiller la piste :

| Fichier | Usage |
|---|---|
| `asphalt.png` | revetement de la piste, a repeter |
| `grass.png` | hors-piste |
| `kerb.png` | bordures rouge et blanc |

Prevoir des textures **repetables** (tuilables) et carrees : 512x512 ou
1024x1024. Au-dela, le chargement dans un navigateur devient sensible.
