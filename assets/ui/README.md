# Interface

Vide en phase 0 : l'interface utilise la police et le theme par defaut de Godot.

A partir de la **phase 2**, pour l'ecran de resultats et le classement :
polices (`.ttf`, `.otf`) et icones (`.png`, `.svg`).

Verifie la licence des polices : beaucoup interdisent la redistribution, et une
police embarquee dans un export web est redistribuee.
